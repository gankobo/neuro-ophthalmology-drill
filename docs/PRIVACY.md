# プライバシー

神経眼科ドリルは、ブラウザの中だけで動くページです。

## データの扱い

- 解答の記録は、お使いのブラウザの中（localStorage）にだけ保存されます。
- 解答の記録を、作成者やほかのサーバーへ送信することはありません。
- 記録はブラウザのサイトデータを消すと消えます。別の端末やブラウザには引き継がれません。

## 公開先について

このページは GitHub Pages で公開しています。ページを開くと、GitHub が通常のアクセス記録（IPアドレス、ブラウザの種類、日時、開いたページなど）を受け取ることがあります。また、文字の表示に Google Fonts を使っているため、Google にも同様の記録が送られることがあります。これらはページのプログラムとは別の、各サービスの方針によるものです。
