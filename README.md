# 神経眼科ドリル（Neuro-ophthalmology Drill）

神経眼科の知識を、5肢複択（正しいもの・誤っているものをすべて選ぶ）形式の問題で確かめるための、ブラウザで動く問題集です。日本神経眼科学会の神経眼科知識評価プログラム（NOKAP）の準備を想定して作りました。

**公開ページ:** https://gankobo.github.io/neuro-ophthalmology-drill/

> これは非公式の学習用教材です。日本神経眼科学会とは関係がなく、学会の過去問や公式の出題範囲にもとづくものではありません。

## 特徴

- 全166問。10の小分野に分かれています。
- **模試（20問）:** 重要度の高い小分野ほど多く出題し、最後にまとめて採点します。
- **分野別:** 1つの小分野を、1問ずつ採点しながら解きます。
- **弱点モード:** 間違えた問題と、正答率の低い小分野から優先して出題します。
- **成績画面:** 小分野ごとの完全正解率を、低い順に表示します。
- サーバーは不要です。成績はブラウザの中にだけ保存されます。

| 小分野 | 問題数 |
|---|---|
| 01 視神経炎・脱髄 | 20 |
| 02 その他の視神経症 | 19 |
| 03 視神経乳頭異常・うっ血乳頭 | 20 |
| 04 視路と視野 | 19 |
| 05 瞳孔 | 18 |
| 06 脳神経麻痺 | 20 |
| 07 核上性・核間性眼球運動 | 15 |
| 08 神経筋・筋疾患 | 15 |
| 09 眼振・めまい | 9 |
| 10 全身・血管・検査その他 | 11 |

小分野の重要度（★）は、神経眼科の標準的な教科書の構成と臨床での重要度から推定したものです。NOKAP の公式の配点ではありません。

## 問題の作り方と注意

問題と解説は、作成者の神経眼科の学習メモと標準的な知識をもとに AI が作成し、別の観点から誤りを点検したものです。それでも誤りや古い記述が残っている可能性があります。必ず教科書や最新の診療ガイドラインで確かめてください。

詳しくは [免責事項](docs/DISCLAIMER.md) をご覧ください。

## プライバシー

成績はお使いのブラウザの中（localStorage）にだけ保存され、どこにも送信されません。詳しくは [プライバシー](docs/PRIVACY.md) をご覧ください。

## 手元で動かす

`index.html` と `questions.json` を同じフォルダに置き、簡単なウェブサーバーで開きます（ファイルを直接開くと、問題データを読み込めません）。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## ファイル

- `index.html` — 問題ページ本体
- `questions.json` — 問題データ（問題文・選択肢・正解・解説・小分野）
